BrewBot supports Discord slash commands and configured text commands. Type `/` in Discord to see the commands available to your account. Discord command permissions and dashboard feature switches can restrict availability.

## Discord slash commands

| Command | Arguments | What it does | Access |
| --- | --- | --- | --- |
| `/ticket` | None | Returns the enabled Speed Tracker public ticket-form link | Form must be configured and enabled |
| `/rank` | Optional `user` | Shows your rank or another member's rank | Premium leveling; rank command enabled |
| `/levels` | None | Shows the server leaderboard | Premium leveling; leaderboard command enabled |
| `/give-xp` | Required `user`, `amount` | Awards XP | Premium leveling, command enabled, Manage Server |
| `/remove-xp` | Required `user`, `amount` | Removes XP | Premium leveling, command enabled, Manage Server |
| `/level-test` | None | Reports leveling configuration and XP diagnostics | No default Manage Server restriction; reports premium status |
| `/remember-birthday` | Required `date` | Saves a birthday for this server | Free birthday feature |
| `/forget-birthday` | None | Removes your saved birthday | Free birthday feature |
| `/meet start` | None; run while in a voice channel | Joins your voice channel and starts [meeting notes](/features/meetings) | Premium meeting notes enabled with a summary channel; allowed roles (everyone if none are set) or Manage Server |
| `/meet stop` | None | Ends the meeting and posts the summary | The member who started it, allowed roles, or Manage Server; anyone in the call for an auto-joined meeting |
| `/meet status` / `/meet optout` / `/meet help` | None | Shows meeting status, opts you out of transcription, or explains the feature | Everyone |
| `/image` | Required `prompt`; optional `image` attachment | Generates an image or uses an attached reference | Premium AI image feature must be enabled |
| `/bot-health` | None | Shows bot health and queue information | Manage Server |

XP amounts accept 1–1,000,000. Birthday dates accept `MM-DD` or `YYYY-MM-DD`.

```text
/rank user:@Jane
/give-xp user:@Jane amount:100
/remove-xp user:@Jane amount:50
/remember-birthday date:03-15
/image prompt:a teapot in a moonlit garden
/ticket
```

`/ticket` returns a link rather than creating a ticket in Discord. `/level-test` checks leveling state rather than sending a sample announcement. `/image` in DMs also requires a shared server with image generation and DMs enabled.

## Prefix commands

Prefix commands are typed as normal Discord messages. They use the **Command Prefix** set in **Configuration > Bot Settings > Basics**, which defaults to `!`. The examples below use `!`.

Built-in prefix commands require premium and only run while **Custom Commands** is **Active** for the server.

| Command | Aliases | What it does | Access |
| --- | --- | --- | --- |
| `!help` | None | Lists your server's custom commands and the enabled built-in commands | Everyone |
| `!rank [@member]` | None | Shows your rank or a mentioned member's rank | Leveling enabled; `!rank` switch on |
| `!levels` | `!leaderboard` | Shows the server leaderboard | Leveling enabled; `!levels` switch on |
| `!givexp @member <amount>` | `!give-xp` | Awards XP | Leveling enabled; `!givexp` switch on; Manage Server |
| `!removexp @member <amount>` | `!remove-xp` | Removes XP | Leveling enabled; `!removexp` switch on; Manage Server |
| `!leveltest` | `!level-test` | Reports leveling configuration and XP diagnostics | Leveling enabled |

The leveling switches are under **Engagement > Leveling > Commands** and control both the prefix and slash versions. XP amounts accept 1–1,000,000.

```text
!rank @Jane
!givexp @Jane 100
!leaderboard
```

Use [Custom Commands](/features/custom-commands) to add your own prefix commands with actions, restrictions, and cooldowns.

## TikTok and Twitch chat commands

These run in the connected platform's live chat, not Discord's slash-command menu:

| Input | Guide |
| --- | --- |
| `// message` | [TikTok TTS](/features/tts) or [Twitch TTS](/features/twitch-tts), when prefix mode is selected |
| `!timer` | [Live Commands](/features/live-commands): start the 180-second Speed Grid timer |
| `!rateme` | [Rate Me](/features/rate-me): join the viewer-photo queue |
| `!play` | [Game Requests](/features/game-requests): join the game queue |
| `!volume` or `!vol` | [Volume](/features/volume): check or change TTS, gift sound, sticker sound, and announcement levels |
| Configured prefix + music command | [Spotify](/integrations/spotify) or [Apple Music](/integrations/apple-music) |

Each live feature has its own enable switch and audience controls. Check its guide before testing a command.
