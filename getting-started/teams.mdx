Teams share access to Discord servers and Slack workspaces. Your personal workspace is separate. Free Discord features stay free; premium access is determined by each server or Slack workspace subscription. Team membership and feature permissions add another layer of access control.

## Create or select a team

Open **Teams** and select **Create Team**, enter a name, and create the team. The creator becomes a team admin. Use the workspace switcher to select your personal workspace or a team; the switcher supports searching, and the sidebar supports starred items.

The team page has **Overview**, **Members**, **Workspaces**, and **Settings** tabs. Workspaces lists its connected Discord servers and Slack workspaces.

## Invite members

Team admins select **Add Member**, enter an email address, and choose Member or Admin. An existing BrewBot account is added immediately; otherwise BrewBot sends an invitation. Active members and pending invitations count toward the team's member limit.

Use **Members** to search the list, open a member's **Permissions**, or revoke a pending invitation. Removing a member immediately revokes their access to the team's servers.

## Team and server roles

| Role | Scope |
| --- | --- |
| **Team Admin** | Manages the team, permissions, and every current and future server. |
| **Member** | Can use allowed servers and the features permitted for that membership. |
| **Server Admin** | A per-server assignment for a team Member. Grants that server's admin tools without making the person a team admin. |

Server Admin does not grant team membership management, team billing, server ownership changes, or management of team-owned shared integrations. Those remain team-admin responsibilities.

## Server access

As a team admin, open a member's **Permissions** and choose:

- **All servers, including future servers**.
- **Selected servers only**, with each server set to **No access**, **Member**, or **Server Admin**.

Save server-access changes before changing other permissions. Selected-server access does not automatically include newly added servers. Team admins always have admin access to all servers, regardless of this selector.

## Feature permissions

| Permission | What it grants |
| --- | --- |
| **Speed Dating** | Host tools on servers where the person has Member access. |
| **Delete Speed Dating profiles** | Profile deletion, together with Speed Dating access. |
| **Dare Grid** | Dare Grid on allowed servers; required separately even for server admins. |

Server admins automatically have Speed Dating and profile-delete access on their designated servers. A feature permission never grants access to a server outside the member's allowed selection.

## Shared settings and usage

Team settings include the default AI model and live-event settings. When team billing is enabled, the team token budget is shared across its Discord servers and Slack workspaces. Usage operates on a rolling 30-day window.

See [Billing](/getting-started/billing), [Speed Tracker](/features/speed-tracker), and [Slack workspaces](/integrations/slack) for their setup flows.
