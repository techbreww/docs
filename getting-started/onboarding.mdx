Start at the [BrewBot Dashboard](https://brewbot.gg). Account onboarding collects your name, connects Discord so BrewBot can find servers you can manage, and sets up your workspace. Feature setup happens afterward on each server's pages.

1. Sign in and enter your first name; your last name is optional. If you signed in with Discord, your Discord name is filled in for you.
2. Select **Continue with Discord** and approve BrewBot in Discord. If you signed in a while ago, you're first asked to confirm it's you with your password or an email code. You return to onboarding automatically. If you signed in with Discord, this step is skipped.
3. Choose how you'll use BrewBot, then continue to the dashboard:
   - **Personal**: just you, managing one Discord server.
   - **Team**: enter a team name to create a shared workspace you can invite admins and members to.
   - If you've been invited to a team, or already belong to one, it's listed so you can join or open it directly. A pending invite is selected by default.
4. Open the install flow and select a Discord server you are authorized to manage. Selecting it reserves it in the dashboard.
5. Complete the bot authorization in Discord, then open the server dashboard.

## Personal or team

| | Personal | Team |
| --- | --- | --- |
| **Who manages it** | Only you | You and the people you invite, as admins or members |
| **Discord servers** | One | Several, managed together |
| **Access control** | Not needed | Per-server access and feature permissions for each member |

You can create or join a team any time later from the workspace switcher or **Teams**. See [Teams](/getting-started/teams) for roles, permissions, and shared settings.

If Discord is connected but no servers appear, reconnect to grant the server-list permission requested by the install flow.

## Find your settings

| Dashboard section | Examples |
| --- | --- |
| **Server Management** | Channels, roles, reaction roles, reports, commands, welcome messages, birthdays, meeting notes |
| **Moderation** | Mod logs, agreements, AutoMod, captcha verification |
| **Engagement** | Horoscopes, platform alerts, leveling, polls, Brewlinks, Messages, Agent Connections |
| **Live Tools** | Monitoring, Speed Dating, and Streaming tools such as TTS, sounds, volume, and overlays |
| **Configuration** | Bot Settings, Integrations, Billing, Permissions, API Logs |

This site's sidebar uses the same sections, so you can follow the dashboard's navigation to find the matching guide.

Basic features are available on the free plan. Premium tools and team permissions are described in [Billing](/getting-started/billing) and [Teams](/getting-started/teams).

## Light and dark mode

The dashboard opens in dark mode. Select the sun or moon button in the top bar to switch between light and dark mode. Your choice is saved in this browser.
