Start at the [BrewBot Dashboard](https://brewbot.gg). Account onboarding collects your name and connects Discord so BrewBot can find servers you can manage. Feature setup happens afterward on each server's pages.

{/* TODO: Add screenshot of account onboarding and install flow */}

1. Sign in and enter your first name; your last name is optional.
2. Use **Connect Discord Account** to link Discord. If needed, add Discord under your profile's connected accounts, then select **I've connected Discord**.
3. Open the install flow and choose a personal workspace or a team.
4. Select a Discord server you are authorized to manage. Selecting it reserves it in the dashboard.
5. Complete the bot authorization in Discord, then open the server dashboard.

Personal workspaces can reserve one server. Use a [team](/getting-started/teams) for shared management. If Discord is connected but no servers appear, reconnect to grant the server-list permission requested by the install flow.

## Find your settings

| Dashboard section | Examples |
| --- | --- |
| **Server Management** | Channels, roles, reaction roles, reports, commands, welcome messages, birthdays |
| **Moderation** | Mod logs, agreements, AutoMod, captcha verification |
| **Engagement** | Platform alerts, leveling, polls, Brewlinks, Messages, Agent Connections |
| **Live Tools** | Monitors, TTS, sounds, overlays, and live events |
| **Configuration** | Bot Settings, Integrations, Billing, Permissions, API Logs |

Basic features are available on the free plan. Premium tools and team permissions are described in [Billing](/getting-started/billing) and [Teams](/getting-started/teams).
