<Tip>
  Starting from Discord? Select **Add App** on BrewBot's profile. It opens **Install BrewBot** in the dashboard; if you're signed out, sign in and you return there, after onboarding if your account is new.
</Tip>

<Steps>
  <Step title="Sign in to the dashboard">
    Go to the [BrewBot Dashboard](https://brewbot.gg) and sign in, then connect your Discord account.
  </Step>
  <Step title="Add your server">
    Open **Install BrewBot**, choose a personal or team workspace, and select the server you want to manage. The dashboard reserves the server before opening Discord authorization.
  </Step>
  <Step title="Authorize permissions">
    Authorize the requested permissions. BrewBot requests only the specific permissions it needs:

    | Permission | Used for |
    | --- | --- |
    | **Kick Members** | AutoMod role enforcement, captcha timeout kicks |
    | **Ban Members** | Captcha verification temp bans |
    | **Manage Channels** | Channel manager, creating channels from dashboard |
    | **Add Reactions** | Reaction roles |
    | **View Audit Log** | Mod logs — identifying who banned, kicked, deleted messages, etc. |
    | **View Channel** | Required for all features |
    | **Send Messages** | Welcome messages, mod logs, alerts, verification |
    | **Manage Messages** | AutoMod link blocking, message deletion |
    | **Embed Links** | All embed-based features (mod logs, alerts, etc.) |
    | **Attach Files** | AI voice messages, image generation |
    | **Read Message History** | Reaction roles, AI chat context, mod log snapshots |
    | **Use External Emojis** | Reaction roles with external server emojis |
    | **Mention Everyone** | Announcement pings in alerts |
    | **Connect** | Voice features, text-to-speech |
    | **Speak** | Voice features, text-to-speech |
    | **Manage Roles** | Reaction roles, captcha verification, leveling rewards |
    | **Moderate Members** | Timeout/mute capabilities |
  </Step>
  <Step title="Open your server">
    Once authorized, your server appears in the dashboard sidebar.
  </Step>
</Steps>

<Warning>
  The requested bot permissions do not bypass channel or category overwrites. If you want the bot to post in a
  specific channel, make sure the bot role is allowed there.

  For locked or private channels, grant the bot role access in the channel itself or in its parent
  category. In most cases that means allowing at least **View Channel**, **Send Messages**,
  **Add Reactions**, and **Read Message History** for the bot role where the message will be
  posted.
</Warning>

<Note>
  You need the **Manage Server** permission in Discord to add BrewBot.
</Note>

## Checking permissions later

If features aren't working, the bot may be missing permissions. Go to **Configuration > Permissions** in the dashboard to see exactly which permissions are granted and which are missing. If any are missing, use the **Re-authorize Bot** button to update them without removing the bot.

See [Permissions](/features/permissions) for details.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Your server isn't listed on **Install BrewBot** | The list only shows servers you own or where you have **Administrator** or **Manage Server**. Servers already set up in another workspace are hidden. If the page says the guilds scope is missing, reconnect Discord. |
| You added BrewBot with an invite link that skipped the dashboard, and the server isn't in it | Sign in, open the server list, and select **Setup** on that server. It connects the server to your current workspace without reinstalling the bot. |
| You can't select a second server | Personal workspaces can reserve one server. Create a [team](/getting-started/teams) to manage more. |
| The install summary stays on **Waiting for Discord...** | Finish the authorization in the Discord tab that opened, and make sure you selected **Authorize**. If you closed that tab, select **Install BrewBot** again. |
| The server dashboard shows **Bot setup needed** and feature pages are unavailable | The bot isn't in the server yet. Open **Configuration > Bot Settings**, select **Add BrewBot**, then select **Check Connection**. |
| **Configuration > Permissions** shows permissions as missing | Select **Re-authorize Bot** and approve every requested permission in Discord. |
| Reaction roles, captcha verification, or leveling rewards don't assign roles | The bot can only manage roles below its own role. In Discord, open **Server Settings > Roles** and drag the bot's role above the roles it assigns. The Permissions page shows the bot's current **Role Position**. |
| The bot can't post in one channel, but the Permissions page shows everything granted | The Permissions page checks server-wide role permissions, not channel overrides. Allow the bot's role in that channel or its parent category. |
| Polls show **Failed** | BrewBot's invite doesn't request **Create Polls**, and the Permissions page doesn't check it. See [Polls permissions](/features/polls#permissions-required). |
| BrewBot appears offline in the member list | If you use your own bot, see [custom bot troubleshooting](/features/custom-bot#troubleshooting). Otherwise, wait a few minutes, then ask in the [support server](https://discord.gg/WbMUYr7DCg) if it stays offline. |
