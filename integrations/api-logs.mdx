Open **Configuration > API Logs** to inspect external integration requests and dashboard timer-control actions. On team servers, this page requires server admin access. Viewing this diagnostic page is not itself a premium feature, although the actions it records may use premium tools.

{/* TODO: Add screenshot of API Logs filters and request details */}

Filter by status (**Success (2xx)** or **Error (4xx/5xx)**) and endpoint. Logged endpoints include external server, timer, and question requests, plus dashboard timer start, reset, and stop actions.

Each entry shows the timestamp, endpoint, method, status, and duration. Expand an entry for available requester details, IP prefix, user agent, or error information. Use these logs when troubleshooting [Stream Deck](/integrations/stream-deck) or live timer controls; this is not a complete log of every Discord request.
