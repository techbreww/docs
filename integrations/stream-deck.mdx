The BrewBot Controls plugin triggers premium Speed Tracker actions from an Elgato Stream Deck. You need access to the server's live-event tools.

## Install and connect

1. Open **Live Tools > Overlays** and expand **Stream Deck Plugin**.
2. Select **Download Plugin** and double-click the downloaded `.streamDeckPlugin` file to install it.
3. In Stream Deck, add a **BrewBot Controls** action to a key.
4. Open that action's settings, sign in through BrewBot, and choose your server.
5. Configure the action and press the key to test it against your live tools.

The bundled plugin requires Stream Deck software 6.9 or later and supports macOS 12 or later and Windows 10 or later.

## Available actions

| Action | Behavior |
| --- | --- |
| **Start Timer** | Starts the shared Speed Tracker timer; configure its duration in the key settings. |
| **Personal Question** | Generates a personal conversation question. |
| **Regular Question** | Generates an icebreaker question. |
| **Spicy Question** | Generates a flirty question. |

Keep the appropriate [overlay](/features/overlays) in OBS to show the timer or generated question. For request failures, check the selected server, account access, and [API Logs](/integrations/api-logs).
