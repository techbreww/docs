Gift Sounds maps TikTok gifts to audio clips. It plays through the same browser source as [TikTok Chat TTS](/features/tts), [TTS Story](/features/tts-story), and [Sticker Sounds](/features/sticker-sounds).

Open **Live Tools > Gift Sounds**. You need access to the server and premium live tools. It works on personal and team servers; on team servers, members need [Speed Dating access](/getting-started/teams#feature-permissions).

## Set up gift sounds

1. Add the TikTok account to [TikTok Chat Monitor](/features/live-monitor).
2. In **Live Tools > TTS Settings > TikTok TTS > Live Source**, select that account as the shared live source.
3. Open **Gift Sounds** and turn on **Enable Gift Sounds**.
4. Use **Add a gift sound** to choose a gift, then select **Add gift**.
5. Select the gift's sound button to open the sound browser, then pick a sound. See [Pick a sound](#pick-a-sound).
6. Turn on the switch for that gift. Changes save automatically.
7. Copy the **Shared Chat TTS overlay** URL into an OBS browser source. If you already have that source, use the existing one.

Both the main switch and the individual gift switch must be on. Choosing **Nothing** leaves a gift silent. **Preview** plays the selected clip in your dashboard browser; it does not simulate a TikTok gift.

<Note>
  Gift Sounds works independently of the Chat TTS text-reading switch. Keep the shared overlay active to play sounds even when chat reading is off. Gifts use the selected shared live source; gifts explicitly addressed to another visible, non-host recipient are skipped.
</Note>

## Pick a sound

The sound browser opens when you select a gift's sound button. Search by name, or filter by category. Select the play button on a card to hear it in your browser, then select the card to use that sound.

The browser includes:

- **Your server’s sounds**: clips you uploaded. See [Upload your own sounds](#upload-your-own-sounds).
- **BrewBot classics**: the original built-in sounds, such as Cash, Heart Pop, and Boat Horn.
- **The sound library**: royalty-free sound effects in eight categories: Alerts & Bells, Hype, Funny, Money, Magic, Impacts, Pops & Dings, and Game.

The library is shared with [Sticker Sounds](/features/sticker-sounds) and the [speed dating timer-end sound](/features/speed-tracker#grid-and-timer-settings). Every library sound comes from [Kenney](https://kenney.nl) or [Freesound](https://freesound.org) under the CC0 public domain license, so you can play it on stream without asking permission or crediting anyone.

## Upload your own sounds

In **Your server’s sounds**, select **Upload sound** and choose a file. After the upload completes, select it from a gift's sound menu and enable that mapping.

The library is shared with [Sticker Sounds](/features/sticker-sounds). A sound you upload on either page is available in both.

| Limit | Supported value |
| --- | --- |
| File format | MP3 or PCM WAV |
| File size | Up to 5 MB |
| Duration | Up to 30 seconds |
| Library size | Up to 50 sounds per server |
| Upload pacing | Wait at least 5 seconds between uploads |

The library shows each file's name, duration, and size. Use **Preview** to check it before assigning it. Uploads belong to the server where you added them; people need server access to manage them, and that server's authorized overlay can play them.

<Warning>
  **Delete** asks you to confirm **Delete sound**. Deleting an upload removes it from every gift and sticker that uses it, and turns those stickers off. Upload it again and reassign it if you need it later.
</Warning>

## Troubleshooting

| Symptom | Check |
| --- | --- |
| No sound after a gift | Confirm the live source, main switch, gift switch, and selected sound. Keep the shared overlay connected and audible. |
| Preview works but OBS is silent | Preview uses your browser's audio. Check the OBS source URL, mixer, and output routing separately. |
| Upload rejected | Export a valid MP3 or PCM WAV. Renaming another format to `.mp3` or `.wav` does not convert it. Trim clips over 30 seconds. |
| Upload button disabled | Wait for the current operation to finish, or delete an unused sound if the library has reached 50. |
| Old overlay stops playing | Copy the current URL after regenerating the Chat TTS link. |

To make gift sounds quieter than chat reading, use [Volume](/features/volume).

Gift sounds enter the shared audio queue. A gift streak can request repeated playback, so clips may wait behind audio already playing.

Timer-end sounds are configured separately in [Speed Tracker settings](/features/speed-tracker#grid-and-timer-settings). That picker includes the sound library but not your uploaded sounds.
