Live tools are BrewBot's premium tools for TikTok, Twitch, music, and live events. Open **Live Tools** after selecting a server in the [dashboard](https://brewbot.gg).

## Monitoring

| Tool | What you can do |
| --- | --- |
| [TikTok Chat Monitor](/features/live-monitor) | Watch TikTok events, inspect observed viewers and moderators, and record sessions. |
| [Twitch Monitor](/features/twitch-monitor) | Monitor Twitch chat and creator events, with chat sending and community panels. |
| [TikTok Rankings](/features/tiktok-rankings) | Explore Daily and Fans Team regional rankings and creator stats. |
| [Transcripts](/features/transcripts) | Review, summarize, and export TikTok recordings before their 24-hour expiry. |

## Stream audio and viewer interaction

| Tool | What you can do |
| --- | --- |
| [TikTok TTS](/features/tts) and [Twitch TTS](/features/twitch-tts) | Read eligible chat through an OBS source or browser player. |
| [TTS Story](/features/tts-story) | Queue longer narration through TikTok's shared audio source. |
| [Gift Sounds and uploads](/features/gift-sounds) | Map TikTok gifts to built-in or uploaded clips. |
| [Gift Goals](/features/gift-goals) | Display a gift target and current count. |
| [Timer Gifts](/features/timer-gifts) | Extend a running countdown once per countdown. |
| [Rate Me](/features/rate-me) | Queue viewer photos with configurable screen time. |
| [Game Requests](/features/game-requests) | Collect `!play` requests and optional Box Battle points. |
| [Live Commands](/features/live-commands) | Control who can use `!timer`. |
| [Spotify](/integrations/spotify) and [Apple Music](/integrations/apple-music) | Enable music requests, playback commands, and track overlays. |
| [Overlays](/features/overlays) | Copy browser-source URLs and preview stream visuals. |

## Live events

Use [Speed Tracker](/features/speed-tracker) for profiles, MVPs, rounds, matches, gift races, and the shared timer. Supporting pages cover [Tickets](/features/tickets), [Schedule](/features/schedule), and [Blocked From Live](/features/live-blocks).

[Dare Grid](/features/dare-grid) has its own players, prompt categories, wins, and timer, with a separate team permission.

## Access and setup

Premium unlocks the features, while team permissions decide which tools you can use. Speed Tracker and several streaming pages require **Speed Dating** access. TTS settings, Live Commands, TTS Story, Twitch Monitor, and music settings require server admin access on team servers. Dare Grid has its own permission. See [Teams](/getting-started/teams).

For TikTok tools, add a monitored channel first and select the appropriate live source. Chat TTS, Gift Race, and several other tools share one source; Rate Me and Gift Goals expose their own source selector. [Platform connections](/integrations/platform-connections) manages account authorization.
