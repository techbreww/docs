Dare Grid organizes a host, co-host, and player boxes for live games. It requires premium and the separate **Dare Grid** team permission. Server admin status or Speed Dating permission alone does not grant Dare Grid access.

{/* TODO: Add screenshot of Dare Grid and prompt panel */}

Open **Live Tools > Dare Grid**. Add a player using their TikTok username, then place players in the host, co-host, or player boxes. Use the waiting-list search to find players, and move participants into **Done** or **Pass** as needed.

- **Pick Player** chooses a participant for the next turn.
- The prompt panel offers **Trivia**, **Funny**, **Embarrassing**, **Gross**, and **Unhinged** categories.
- Use the timer for a challenge.
- Add or remove wins on player cards and review **Top Wins**.
- Edit or delete players, or use **Clear Board** when preparing another round.

Ask your team admin to enable Dare Grid for your membership if it is missing from the navigation.
