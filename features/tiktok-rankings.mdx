**Live Tools > TikTok Rankings** shows regional leaderboards and creator statistics. This is a premium feature.

{/* TODO: Add screenshot of TikTok Rankings */}

Choose **Daily** or **Fans Team**, then select a region. Search the returned leaderboard by name or TikTok username and select a creator to inspect their statistics.

The page can show rank, diamonds or score, the gap to the next place, followers, following, and the ranking reset time. A dash means TikTok did not supply that value. Reset times are displayed in your local time, and the countdown is based on the displayed snapshot.

Rankings load when you open the page. Use **Refresh** for an update; requests within a minute share the latest snapshot. If a refresh fails, the page retains the last successful results.

Connect TikTok under [Integrations](/integrations/platform-connections) to show your connected account. If profile access needs reauthorization, reconnect there. Regional rankings remain available without that profile.
