Welcome messages are available on the **free plan**. BrewBot sends your configured text when a member joins.

{/* TODO: Add screenshot of Welcome Message editor and preview */}

1. Open **Server Management > Welcome Message**.
2. Enable **Send a message when a user joins the server**.
3. Select an existing welcome channel or create one from the channel picker.
4. Write a text message of up to 2,000 characters and check the preview.
5. Use **Send Test**, then publish the settings.

| Placeholder | Value |
| --- | --- |
| `{user}` | Mention of the new member |
| `{server}` | Server name |
| `{member_count}` | Total member count |
| `{user.tag}` | Member's Discord tag |
| `{user.id}` | Member's Discord ID |

```text
Hey {user}, welcome to **{server}**! You are member #{member_count}.
```

The bot needs **View Channel** and **Send Messages** in the welcome channel. Use [Reaction Roles](/features/reaction-roles) or [Captcha Verification](/features/captcha-verification) to manage onboarding roles. The welcome editor currently supports text messages; its embed option is marked as coming soon.
