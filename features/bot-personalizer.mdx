Open **Configuration > Bot Settings** to manage your bot. Basic setup is available on the **free plan**. Backstory, AI chat, voice, and image generation require **premium**. On team servers, modifying these settings requires server admin access.

## Basics

Use **Basics** to sync the latest Discord server name and icon, choose an embed color and command prefix, and check the bot connection. Re-authorize the bot when requested permissions need updating; private channels still need to allow the bot in their own permissions.

A [custom bot](/features/custom-bot) enables its own avatar, name, status, and activity. BrewBot applies a seven-day cooldown to bot name changes. Changing a custom bot's username affects every server where that bot is installed.

## Backstory and AI chat

The **Backstory** tab includes:

- A backstory of up to 2,000 characters, with a randomize option.
- **Enable AI Chat** and a trigger mode: **Mention Only**, **Allowed Channels**, or **Both**.
- Allowed channels for automatic responses and **Allow DMs**.
- **Enable Image Generation**, which enables `/image` with a prompt and an optional reference image.

<Warning>
  **Clear Conversation History** permanently removes the server's stored Discord AI conversation memory. It is separate from iMessage memory.
</Warning>

## Voice

Enable voice features and select an AI voice. Choose **Standard** or **Expressive (Beta)** quality. **Voice Notes** controls audio replies in selected text channels; **Voice Speech** controls spoken responses in selected voice channels.

Stream chat TTS is configured separately under [Live Tools > TTS Settings](/features/tts).

## AI usage

**AI Usage** shows requests, input/output tokens, and model breakdowns. Token budgets use a rolling 30-day window: usage falls as older requests leave that window. Team-managed limits are configured through [Teams](/getting-started/teams).

Budget-alert controls marked **Coming soon** are not active functionality.
