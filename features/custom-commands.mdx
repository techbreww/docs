Create custom Discord commands under **Server Management > Custom Commands**. The current editor creates prefix commands that send text or embeds. Each server can have up to 500 custom commands.

1. Select **New custom command**.
2. Enter the command name. The editor shows the server’s configured prefix.
3. Add message actions: send in a predefined channel or respond in the current channel.
4. For message actions, enter text and optionally add an embed. Add multiple response choices when you want the bot to choose randomly.
5. Configure **Advanced options and permissions**, then save or publish the command.

Advanced settings include a command description, allowed and denied roles, allowed and denied channels, cooldown in seconds, and hiding command usage. Enable or disable individual commands from the command list.

The bot needs access to any destination channel. Use the prefix configured in [Bot Settings](/features/bot-personalizer). Role assignment and removal appear as unavailable actions in the current editor; they are not selectable setup options. Built-in slash commands are listed separately in the [command reference](/bot-commands/reference).

The custom-command list also points members to the prefix `help` command to discover available commands. [Live Commands](/features/live-commands) controls TikTok commands separately.
