Brewlinks creates public link pages for your server or creator brand. You can manage up to **five pages per server**, each with its own URL and branding.

## Create a page

1. Open **Engagement > Brewlinks** and select **New Page** or **Create First Page**.
2. Set a unique **Slug**, which becomes `https://brewlinks.gg/your-slug`.
3. Enter a title, optional subtitle, and accent color.
4. Select **Add link** and enter each link's title and full HTTP or HTTPS URL. Reorder links as needed.
5. Enable **Enable public page**, save your changes, and use **Open page** to check the result.

Slugs use lowercase letters, numbers, and single hyphens between words. They must be unique across BrewBot. Favicons are fetched automatically for your destinations.

Use **Copy URL** to share a page in social profiles, Discord, or stream descriptions. Links shared before the move to brewlinks.gg, in the form `brewbot.gg/brewlinks/your-slug`, redirect to the new address. Disabling the public page hides it from visitors while preserving its settings.

## Change the logo

Each page shows your Discord server icon by default and follows it when the icon changes. To use a different image, click the logo in **Branding** or **Live Preview** (look for the pencil) and choose a PNG, JPEG, WebP, or GIF up to 2 MB. The new logo goes live right away, without saving. Select **Use server icon** to switch back.

You can also manage Brewlinks pages from the [iOS app](/getting-started/ios-app#manage-brewlinks).

<Warning>
  Deleting a Brewlinks page permanently removes the page and its links. Disable it instead if you only want to hide it temporarily.
</Warning>
