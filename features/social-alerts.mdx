Social alerts send notifications into Discord. Open the platform's page under **Engagement > Alerts**. These premium features require a connected bot with access to the destination channel.

## TikTok, Twitch, and Kick

Create an alert, choose the creator and Discord channel, and customize the message using the platform editor. Enable the alert and save it. TikTok has a separate **Live notifications** switch and message.

Twitch and Kick offer **Auto-refresh** for the live notification and **Auto-delete** when the stream ends. Twitch channel records can also be used for [TTS](/features/twitch-tts) and [Twitch Monitor](/features/twitch-monitor), which require broadcaster authorization for chat and events.

TikTok's [monitor watch list](/features/live-monitor) is separate from its Discord alert list. Adding a monitor does not create an alert.

## YouTube LIVE

The current YouTube alert flow tracks live streams. Open an alert to see push status, lease expiry, last push, last live check, and recent events.

- **Retry push** requests push verification again.
- **Check now** performs a one-time live check. Discord delivery still occurs on the bot's delivery cycle.
- **Reset state** clears saved watch state before another attempt.

Configure the destination, alert message, and whether to refresh or delete the live message. If the page reports that YouTube is not configured, contact support.

## OnlyFans posts

OnlyFans alerts are in beta and require a connected creator account under [Integrations](/integrations/platform-connections). Team admins manage the shared connection through the independent OnlyFansAPI sign-in provider.

1. Connect the creator, then open **Engagement > OnlyFans Alerts**.
2. Choose an **Age-restricted Discord channel** and optionally a role to mention.
3. Customize the message using the editor's placeholders.
4. Enable notifications and select **Save alert**.
5. Use **Send test notification** to verify the saved settings.

Posts published before the alert was enabled are not announced. Link previews are suppressed, and only the selected role can be mentioned.

Automatic checks require automatic checking to be enabled on the connection and an enabled, saved alert. A manual **Check for new posts** uses provider credits and has a five-minute cooldown. Test notifications use saved settings without consuming provider credits. Review recent deliveries and use **Retry failed deliveries** when needed.
