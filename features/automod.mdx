## Role enforcement

Enable **Role Enforcement**, choose a required role, and set a grace period of 1–30 days after joining. Members still missing the role after that period can be kicked. Optionally set the kick reason and log channel.

The bot checks periodically, so enforcement is not an exact countdown. It needs **Kick Members** and sufficient role hierarchy to kick a member.

## Link blocking

Enable **Link Blocking** and add the channels where it should apply. Configure:

- **Bypass Roles** for members allowed to post restricted content.
- **Allow same-server links** for Discord links to messages or channels in your server.
- **Block attachments** and **Block stickers**.
- A warning message using `{user}` to mention the member. The warning auto-deletes after five seconds.
- An optional log channel.

The bot needs **Manage Messages** in enforced channels and **Send Messages** for warnings and logs.

## Spam protection

Spam protection detects links, attachments, or stickers posted across **two or more channels** in the rule window. It has two separately configurable rules:

| Rule | Window |
| --- | --- |
| **New Members** | The configured number of seconds after joining |
| **Current Members** | A fixed 60-second cross-channel window for members outside the new-member window |

Choose **Delete message and kick member** or **Delete message only** for each rule. Set a kick reason and optional log channel where appropriate. The new-member rule runs before the current-member rule.

Add **Excluded Roles** to skip spam protection for trusted roles. This list is separate from Link Blocking's bypass roles. Review both lists rather than assuming a role excluded from one rule is excluded from the other.

<Note>
  A single link in one channel is not the cross-channel spam trigger. It can still be deleted by Link Blocking if that channel enforces link restrictions.
</Note>
