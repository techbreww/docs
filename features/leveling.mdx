Leveling rewards eligible messages with XP and ranks members on a server leaderboard. Open **Engagement > Leveling** to enable it.

{/* TODO: Add screenshot of Leveling settings */}

## Configure XP and announcements

Set the **XP Rate** multiplier to control progression. Use **No-XP Channels** and **No-XP Roles** to allow all except selected entries or deny all except selected entries.

Choose a level-up announcement mode: **Disabled**, **Current Channel**, **Private Message**, or **Custom Channel**. Customize the announcement with the placeholders offered by the editor.

XP is subject to eligibility and cooldown rules; sending repeated messages does not guarantee XP for every message.

## Role rewards

Add a role and the level required to earn it. Choose whether members **Stack previous rewards** or **Remove previous rewards** to keep only their highest reward. You can also remove a reward after a member loses enough XP.

The bot needs **Manage Roles** and must be above reward roles. Rank-card customization marked **Coming Soon** is not available yet.

## Commands

| Command | Use |
| --- | --- |
| `/rank` | Your rank, or another member's rank using the optional `user` argument |
| `/levels` | Server leaderboard |
| `/give-xp user:@Jane amount:100` | Award XP; requires Manage Server |
| `/remove-xp user:@Jane amount:50` | Remove XP; requires Manage Server |
| `/level-test` | Inspect subscription, leveling settings, XP, rewards, and command status |

Use the command switches to enable the supported rank, leaderboard, and XP controls. `/level-test` returns a diagnostic report rather than sending a sample level-up announcement. See the [command reference](/bot-commands/reference).
