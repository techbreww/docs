Twitch TTS reads messages from a connected Twitch broadcaster's chat. It requires premium and server admin access on team servers. Its source, settings, audio queue, and overlay are separate from [TikTok TTS](/features/tts).

## Connect a source

1. Open **Live Tools > TTS Settings > Twitch TTS**.
2. Search for a channel in **Source Library** and select **Add source**.
3. Select **Connect channel** and authorize as the matching broadcaster.
4. Select that source for TTS. You can save several sources, but only one is active for TTS at a time.
5. Enable Twitch TTS and configure the trigger, audience, and voice.
6. Copy the overlay URL into OBS or select **Open Browser Player**.

Sources are shared with [Twitch Monitor](/features/twitch-monitor) and Integrations. Reconnect the broadcaster if the source reports an authorization error or requests additional Monitor permissions. The source library also lets you disconnect, enable/disable, or remove sources.

## Trigger and audience

**Use // prefix** requires eligible viewers to start their message with `//`. **Read messages normally** reads eligible messages without that prefix. **Allow Privileged Users Without //** grants a prefix bypass to the broadcaster, moderators, and VIPs.

| Audience | Eligible viewers |
| --- | --- |
| **Broadcaster + Moderators** | Broadcaster and moderators |
| **VIPs + Staff** | VIPs, broadcaster, and moderators |
| **VIPs + Broadcaster** | VIPs and broadcaster |
| **Everyone** | All chatters, subject to access lists |

**Whitelisted Users** can bypass audience restrictions. Whitelisting adds eligibility without removing access already granted by the selected audience. **Blocked Users** always wins: a blocked username cannot trigger TTS even if it is also whitelisted.

<Note>
  New Twitch TTS requests are skipped while the server’s Speed Tracker timer is running, even though Twitch uses a separate queue and overlay.
</Note>

## Voice settings

Choose **Single voice** or **Random voices**, and select **Eleven Multilingual v2** or **Eleven v3**. Random mode retains the saved single voice as a fallback. Assign **Custom User Voices** to give specific Twitch usernames a fixed voice that overrides the default or random mode.

See [voice models and audio tags](/features/tts#voices-and-audio-tags) for expressive speech examples.

## Overlay, browser player, and queue

The **Overlay & Queue** section provides the OBS URL, preview, token regeneration, and **Browser Player** link. The browser player runs on another device with a visible queue and playback controls. Select **Enable audio** if the browser blocks playback.

**Clear pending** removes pending jobs. A player claims jobs for playback; multiple open playback sources do not mirror every message to every device. Keep the intended source audible in your streaming setup.

<Warning>
  Regenerating the token invalidates existing Twitch TTS overlay and player URLs. Replace them in OBS and on any playback devices. Keep token-bearing links private.
</Warning>
